# Weekly Project Plan — Stock Market Analysis

## Week 1 — Topic & Research Paper
- Finalize the Stock Market Analysis topic.
- Select the base research paper.
- Understand the paper's Random Forest / ensemble approach.

## Week 2 — Dataset Collection
- Collect historical Indian market data.
- Use OHLCV fields such as Open, High, Low, Close and Volume.
- Document the dataset source and date range.

## Week 3 — Data Preprocessing
- Clean missing values and invalid records.
- Sort observations chronologically.
- Create technical-indicator features.

## Week 4 — Base Model Reproduction
- Implement the Random Forest Regressor workflow.
- Use a time-aware train/test split.
- Generate predictions.

## Week 5 — Evaluation
- Calculate MAE, MSE, RMSE, MAPE and R².
- Add Directional Accuracy.
- Compare project results with the paper's reported results.

## Week 6 — Proposed Model
- Implement Extra Trees Regressor.
- Use TimeSeriesSplit and parameter tuning.
- Save the best model and feature importance.

## Week 7 — Model Comparison
- Compare Random Forest and Extra Trees.
- Prepare tables and charts.
- Document observations and limitations.

## Week 8 — Final Project & Website
- Finalize the drafted paper.
- Add results and dataset documentation.
- Publish the project dashboard with GitHub Pages.
- Prepare the ZIP submission with paper, code and documentation.
