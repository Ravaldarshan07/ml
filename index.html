Project Overview

This project studies a published stock-return prediction approach, reproduces a Random Forest workflow, and evaluates Extra Trees as a proposed ensemble alternative.

Base modelRandom Forest
Proposed modelExtra Trees
DatasetNIFTY 50 sample

8-Week Project Progress

Week 1 — Research Paper

Finalize topic, select the base paper and understand its ensemble-learning approach.

Week 2 — Dataset

Collect historical Indian market data and document OHLCV fields and source.

Week 3 — Preprocessing

Clean data, sort chronologically and create technical-indicator features.

Week 4 — Random Forest

Implement the base Random Forest workflow and generate predictions.

Week 5 — Evaluation

Calculate MAE, MSE, RMSE, MAPE, R² and Directional Accuracy.

Week 6 — Extra Trees

Implement the proposed Extra Trees model with time-series validation.

Week 7 — Comparison

Compare both models, prepare charts and document observations.

Week 8 — Final Submission

Finalize paper, code, dataset documentation and the project website.

Stock Market Dataset

A small NIFTY 50 historical sample is included in the repository at data/nifty50_sample.csv. It contains Date, Price, Open, High, Low, Volume and Change %.

Academic Note

The NIFTY 50 sample in this repository is a small demonstration dataset. For final model training, use a sufficiently large, documented historical dataset and cite its source. Project-run metrics should not be presented as an exact reproduction of the original paper unless the original data and preprocessing are independently verified.
